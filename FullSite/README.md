# Летопись дня — Собранный сайт

Эта папка содержит полностью собранный и готовый к развертыванию сайт «Летопись дня».

## Структура файлов

```
FullSite/
├── index.html          # Главная страница с SEO-оптимизацией
├── sitemap.xml         # Карта сайта для поисковых систем
├── robots.txt          # Инструкции для поисковых роботов
├── assets/
│   ├── index-*.css     # Минифицированный CSS (34 KB)
│   └── index-*.js      # Минифицированный JavaScript (205 KB)
└── README.md           # Этот файл
```

## Как использовать

### Локальный запуск

1. Откройте `index.html` в браузере
2. Сайт готов к работе!

### Развертывание на сервере

Просто скопируйте все файлы из папки `FullSite` в корень вашего веб-сервера:

```bash
# Пример для Nginx
sudo cp -r FullSite/* /var/www/html/

# Пример для Apache
sudo cp -r FullSite/* /var/www/html/

# Пример для Netlify/Vercel
# Просто загрузите содержимое FullSite через веб-интерфейс
```

### Docker

```dockerfile
FROM nginx:alpine
COPY FullSite/ /usr/share/nginx/html/
EXPOSE 80
```

## Особенности

### SEO-оптимизация

✅ Динамические title и description для каждой даты  
✅ Open Graph и Twitter Cards для соцсетей  
✅ Структурированные данные JSON-LD (WebSite + Event schema)  
✅ Семантическая HTML-разметка с itemprop  
✅ Оптимизированные изображения (alt, lazy loading, dimensions)  
✅ sitemap.xml и robots.txt  
✅ Canonical URLs для каждой даты  
✅ Оптимизация производительности (неблокирующие шрифты, lazy loading)  
✅ Доступность (ARIA, семантика, фокус-стили)  

### Функциональность

- **Ежедневное обновление**: сайт автоматически показывает события текущего дня
- **Навигация по датам**: можно листать дни, месяцы, выбирать конкретную дату
- **Фильтры по эпохам**: Древний мир, Средние века, Новое время, XIX-XX вв., Современность
- **Поиск**: поиск по всем событиям дня
- **Статьи из Википедии**: подробные описания событий с ссылками на первоисточники
- **Офлайн-режим**: встроенный архив статей для дат 2-4 сентября
- **Адаптивный дизайн**: работает на всех устройствах

### Производительность

- CSS: 34 KB (gzip: 7.4 KB)
- JS: 205 KB (gzip: 66 KB)
- Неблокирующая загрузка шрифтов
- Lazy loading для изображений
- Оптимизированные анимации

## Технологии

- **React 18** — UI библиотека
- **Vite** — сборщик
- **Tailwind CSS v4** — стили
- **TypeScript** — типизация
- **Wikipedia API** — источник данных

## Источники данных

1. **Википедия API** (основной): `https://api.wikimedia.org/feed/v1/wikipedia/ru/onthisday/all/{MM}/{DD}`
2. **Википедия API** (запасной): `https://ru.wikipedia.org/api/rest_v1/feed/onthisday/all/{MM}/{DD}`
3. **Встроенный архив** (офлайн): готовые статьи для дат 2-4 сентября
